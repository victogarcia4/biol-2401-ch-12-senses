# Chapter 12: Nervous System III — General & Special Senses

An interactive, web-based anatomy & physiology presentation built with **HTML5, CSS3, and Vanilla JavaScript** (with GSAP animations), styled according to the **Lone Star College Brand & Logo Style Guide**, and structured around the **Student Learning Objectives (SLOs)** of *Hole's Human Anatomy & Physiology (15th Edition), Chapter 12*.

## Features
- **8 Structured Student Learning Objectives (SLOs)** covering General Senses, Pain Pathways, Olfaction, Gustation, Hearing, Equilibrium, Vision Optics, and Photoreception/Life-Span Changes.
- **1 Anatomical Image per Slide**, combining high-resolution anatomical models from the `12 Senses` collection with custom scientific illustrations generated with Nano Banana 2.0.
- **Bloom's Taxonomy (Analysis Level) Knowledge Checks** after every SLO, featuring clinical and physiological scenarios, immediate diagnostic feedback, detailed rationales, and live mastery tracking.
- **Lone Star College Visual Identity**:
  - Primary Colors: LSC Blue (`#003768`) & LSC Red (`#b30838`)
  - Secondary Colors: Tan (`#f1c585`), Light Blue (`#c7eafb`), White (`#ffffff`), Black (`#000000`)
  - Typography: Trajan-inspired Display Serif (`Cinzel`), Futura-inspired Geometric Sans (`Jost`), and `EB Garamond` for editorial copy.
- **Interactive Controls**: Keyboard navigation (`←`/`→`, `Space`, `F` for fullscreen, `O` for slide overview), clickable SLO progress rail, image zoom lightbox, and printable Mastery Scorecard.

## Local Preview
Open `index.html` with any static server, for example:
```bash
npx serve .
```

## Deploy to Netlify
This repository includes a pre-configured `netlify.toml`.
1. Push this repository to GitHub.
2. In Netlify, select **Add new site → Import an existing project** and connect your GitHub repository.
3. Leave the build command blank and set the publish directory to `.` (automatically read from `netlify.toml`).
